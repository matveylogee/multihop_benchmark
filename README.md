# MultiHopBench

Factual question-answering benchmarks often reduce correctness to a short exact-match target, obscuring failures in inverse retrieval, list completion, simultaneous constraint satisfaction, and no-answer recognition. We introduce MultiHopBench, a benchmark for multi-hop and multi-constraint factual question answering that links natural-language requests to structured constraints and formally verifiable answers. Its Wikidata-derived core is complemented by curated external examples and validated zero-gold near misses. Parallel Russian formulations support evaluation of Russian-oriented systems on the same underlying tasks without making multilinguality the primary focus. We further define a constraint-aware evaluation architecture in which an LLM judge emits only atomic entity- and constraint- level labels under a strict schema, deterministic code validates the annotation and recomputes all metrics, and a calibrated scorer produces interpretable per-query and aggregate scores. This design supports diagnostic analysis beyond exact match while keeping numerical evaluation auditable and reproducible.
